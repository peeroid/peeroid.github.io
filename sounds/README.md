# Notification Sounds

This directory contains audio files for notification sounds.

## Available Sounds

- `notification.mp3` - Default notification sound for incoming messages

## Adding New Sounds

To add a new notification sound:

1. Place the audio file in this directory
2. Update the sound utility to reference the new file path
3. Ensure the audio file is optimized for web use (small file size, common format)

## Supported Formats

- MP3
- WAV
- OGG
